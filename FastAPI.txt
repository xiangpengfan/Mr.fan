数据类型
python在定义数据时可以声明数据类型，这在fastapi中有很重要的作用

定义类型只需要在变量后方加上冒号和类型名称即可，以下：
def main(name：str)     #表示这个类型只能是字符串

定义类型的关键点在于类型的种类和类型的定义方式
特殊的定义方式：泛型和多类型union
泛型
在容器作为被定义的类型时，容器内部的元素可以继续声明类型，这种容器套类型的形式叫做泛型，以下：
def main(name：list[])    #定义容器做类型  
def main(name：list[str]) #定义容器并且规定容器内数据只能是str，就是定义泛型
def main(name：list[int,int，str])  #这表示容器内有三个元素，分别是整数，整数，字符串的形式

多类型
一个变量可以为多类型中的任意一种，我们用多类型定义它，以下：
def main(name：str，score：int|float)    #int|float表示score既可以是整数类型又可以是小数类型
def main(name：str，score：int|float，a：list[]|tuple[])  #a既可以是列表又可以是元组
类型中间加竖杠表示变量可以属于多个类型中的一种


Pydantic:一个对数据进行过滤的模块
过滤操作重要的点有两个：滤网和过滤方法
滤网：把想要的数据定义在一个目标类中，并给数据附上类型
过滤的方法：将原始数据做参数传入目标类生成一个实例
过滤操作：
把想要提取的数据定义成一个目标类，用目标类去过滤原始数据得到干净的目标数据，以下：
class User(BaseModel):                #把想要是数据定义在目标类中并附上数据类型，相当于定义了一个滤网
    id: int
    name: str = "John Doe"
    signup_ts: datetime | None = None
    friends: list[int] = []

external_data = {                           #原始数据
    "id": "123",
    "signup_ts": "2017-06-01 12:22",
    "friends": [1, "2", b"3"],
}

user = User(**external_data)        #把数据通过滤网生成一个类的实例,这算是完成了过滤
#该实例过滤掉了所有我们不需要的元素，并且在过滤过程中改写一些数据的类型，如:‘30’--->30;使这些数据更符合我们的需求

环境变量：保存在计算机中，常常用来保存程序的路径或者其它配置

配置：程序需要的参数，通常相对不变，并且通常不在程序中出现。以下：
数据库的密码端口地址，用户名；这些是相对不变的，需要输入的，通常不在代码中出现的参数，叫做数据库程序的配置
如果把我们写好的程序想象成一个精密的机器，配置文件就像是一份完整的调试说明书，机器会自动读取这份说明书

环境变量实现方式
$Env:MY_NAME = "Wade Wilson"  #在命令行中创建一个临时的环境变量
MY_NAME="Wade Wilson" python main.py  #在python程序运行之前创建一个只针对该程序的环境变量

$Env:MY_NAME       #在命令行中读取环境变量
name = os.getenv("MY_NAME"，默认输出）   #在python中读取环境变量，若没有会输出默认值

path环境变量详解
当你在path环境变量中加入程序路径后，你在powershell中输入程序名称可以直接查找该程序的路径，并启动它
例如，当你在终端中输入 python 时，操作系统会在该列表中的第一个目录path中查找名为 python 的程序。

fastapi：快速开发，快速运行，并会自动生成接口文档，以便网站调试或者开发者协作开发

实现方式
from fastapi import FastAPI

app=FastAPI()     #创建命令对象

@app.get(''/)        #定义路由地址和操作方式--get
async def root():
    return {"message": "Hello World"}
#开发 API 时，路径是把一坨大问题划分成小问题的主要手段


关于接口文档
接口文档就是网站的说明书，接口文档的写作模式就叫模式，常用的模式是OpenAPI
这个模式规定了文档必须包含的内容：接口地址，请求方式，请求头，请求参数等
在fastapi中这些文档最终写成json的形式并输出成openapi.json文件，以下：
http://127.0.0.1:8000/redoc：接口说明书
http://127.0.0.1:8000/docs：在线调试文档


关于多命令对象的选择
当一个py文件里定义了好几个网站时，注意是网站不是网页，必须确定要启动哪一个网站。以下：
 ##py文件
app = FastAPI()        # 主 API
admin_app = FastAPI()  # 后台管理 API    #两个命令对象定义了两个网站

传统方式
fastapi dev main.py --app app   #启动时必须指定具体的命令对象

另一个方式
在pyproject.toml文件加上固定配置
[tool.fastapi]
entrypoint = "main:app"   #永久性的实现了指定命令对象
等价于
fastapi dev main.py --app app

路由：又叫路径，是浏览器访问网页的地址，定义在装饰器中，与处理函数成对出现



路由分为静态路由和动态路由
静态路由’/files/name‘：常见的访问网站的地址；动态路由’/files/{name}‘：路由不固定，name位置的参数可以传递给后端

路由顺序：
1.一个路由只能对应一个处理函数，以下：
@app.get("/users")                      @app.get("/users")
async def one():                            async def two():
#访问"/users"时，只会运行第一个处理函数，第二个处理函数def two()无法被启动
2.动态路由必须位于静态路由之下，如果相反，静态路由将无法被匹配到。以下：
@app.get("/users/{user_id}")
async def one(user_id: str):

@app.get("/users/me")
async def two():
#访问"/users/me"时，路由从上到下匹配，匹配到"/users/{user_id}"满足条件将不会再往下匹配,最终只会出发def one(),def two()被def one()覆盖掉了
#反之，访问"/users/me"时，先two后one没有任何问题



预设动态路由值
预设值需要两步：将预设值装入容器中+对路由值校验，非预设值无法传入
标准做法：常用容器list、tuple、dict+if判断
更优雅省时的做法：定义一个枚举类容器，并在传输处理函数时声明参数类型，以下：
class ModelName(str, Enum):    #Enum使类变成一个枚举容器，并给容器中的每一个元素设置新的数据类型ModelName
    alexnet = "alexnet"                 #str限制类中定义的元素只能是字符串类型
    resnet = "resnet"
    lenet = "lenet"           

@app.get("/models/{model_name}")
async def get_model(model_name: ModelName):   
#只允许ModelName类型的数据输入，而ModelName类型的数据只有三个，就相当于预设了这3个数据



动态路由传路径参数的方法
因为路径和路由都是由‘/’连接而成，所以只用‘/{}’无法捕捉路径，以下：
访问路径
/files/code_FastAPI\awesome-project\main.py    #无法知晓哪一个是需要捕捉的路径

引入捕获路径参数并传入后端的方法，在@app.get()中设置 "/files/{file_path:path}"，以下：
/files\\code_FastAPI\awesome-project\main.py   #通过双斜杠可以很轻松的判断出传入后端的参数 code_FastAPI\awesome-project\main.py

以下是完整实例：
后端实设置
@app.get("/files/{file_path:path}")     #采用file_path:path
async def read_file(file_path: str):
    return {"file_path": file_path} 

浏览器访问
/files\\code_FastAPI\awesome-project\main.py 

网页返回值
"file_path": code_FastAPI\awesome-project\main.py

查询参数：没有在路由路径中预先占位，而是以?key=value&...形式附加在URL末尾的可选参数。以下：
@app.get(("/items/")     #定义时路由中未定义查询参数
http://127.0.0.1:8000/items/?skip=0&limit=10    #查询时加载路由？后，以&连接


查询参数：类型声明和默认值的设置

声明类型
和路由参数定义一样，查询参数也可以声明类型，包括多类型。以下：
@app.get("/items/{item_id}")
async def read_item(item_id: str, q: int | None = None，skip:bool=false):       #给可选参数q设置int或者None类型

类型转换：字符串str和数字int可以在输入时相互转换。以下：
http://127.0.0.1:8000/items/？q=12       #路径参数默认是str形式，函数参数只接受int形式，会在框架中做默认转换
http://127.0.0.1:8000/items/?skip=20    #任何数值的数据除0外，都会被转换为bool值true


设置默认值
就像路径参数定义时一样，查询参数定义时也可以设置默认值，以下：
@app.get("/items/")
async def read_item(skip: int = 0, limit: int = 10):   #设置默认值后，即使在访问时未输入查询参数，函数也会以参数函数的默认值允许

必选查询参数
没有设置默认值的参数称为必选参数，访问时必须传入路由，否则会报错，以下：         #传入路由的方式可以参照本节首段
@app.get("/items/")
async def read_item(skip: int, limit: int):                 #在访问/items必须传入skip和limit，否则函数无法运行

请求参数----用来处理和获取请求体数据

获取数据，从请求体中
定义Basemodel子类，并在处理函数中声明该类，对应的参数会自动捕捉请求体中的同名数据，以下：
class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tax: float | None = None          #定义Basemodel子类

@app.post("/items/")
async def create_item(item: Item):    #在函数中声明它，参数item会自动捕获请求体中的同名数据
注意：和路由参数与查询参数类似，请求体参数也可以声明类型，设置必选参数，设置默认参数，不过都是在BaseModel子类中设置


使用数据
和类调用属性相同，通过类.方法(),来使用捕获的数据
@app.post("/items/")
async def create_item(item: Item)：
         item.name=name的值
         item.description=description的值
         item.price=price的值
         item.tax=tax的值
注意：同样是创建类，使用枚举，可以严格限制参数的可选范围，将其锁定在预先定义好的几个合法值中；使用Basemodel子类，则是可以使参数直接从前端捕获数据。这有重大区别，并且枚举类可以作为Basemodel子类的属性类型声明，限制子类属性的取值范围，以下：
class enum(Enum):
    str1 = "a"                 
    str2 = "b"
    str3 = "c"    

class Item(BaseModel):
    name: enum
#name的值被限制在了’a‘’b‘’c‘之间


最后总结：
根据不同位置（URL 里、问号后、Body 里）传来的数据，我们在函数里定义参数的方式也不一样：
1.从路由中获取数据-----路由参数
定义时与路由中的{可变路径}同名，def def create_item(item_id:int)；@app.get("/items/{item_id}")
可以从路由中捕获数据，用在参数中接收

2.从请求体中获取数据-----请求体参数
定义时参数声明BaseModel 子类，async def create_item(item: Item)；class Item(BaseModel):
可以从请求体中捕获数据，并用参数接收

3.从路由？后面获取数据------查询参数
定义时声明了参数类型，但是既没有继承BaseModel子类，又没有与路由中的‘{可变路径}’同名，那么这个参数就是查询参数
可以从路由的？后面捕获数据，并用参数接收
