流式数据StringResponse
流式数据：发送纯粹的不加修饰的原始数据
作用：大模型文字显示，视频/图片传输，特大型文件传输

回顾：序列化，把活的数据转换成可以传输的形式-json、bytes等


实现方式
#在路由参数中添加response_class
@app.get("/story/stream-no-async", response_class=StreamingResponse)
def stream_story_no_async() -> Iterable[str]:   #这个注释可有可无
    for line in message.splitlines ():
        yield line                                            #数据分段传输

自定义http请求
class PNGStreamingResponse(StreamingResponse):
    media_type = "image/png"
    status_code="状态码"
@app.get("/story/stream-no-async", response_class=PNGStreamingResponse)
#直接使用PNG就可以自定义HTTP请求


respons_model和response_class的区别
response_model负责校验和把数据转化成可传输的形式，response_class负责修饰http的请求头、状态码和编码方式
在fastapi中可以用类型注解来替代response_model使用，效果完全相同--校验和序列化数据
StringResponse传输的是原始数据，不需要序列化也不需要校验，所以完全可以不用类型注释/response_model

路由参数和手写文档
路由参数
1.operation_id=:给路由设置唯一的id号
使用方法
@app.get("/items/", operation_id="唯一id")

3.include_in_schema=:禁止该路由出现在文档中
使用方法
@app.get("/items/", include_in_schema=False)

@app.post(
    "/items/",

附件：json的数据格式
附：一个完整的openapi.json对象由6部分构成
"openapi": "3.1.0",          // ← OpenAPI 版本
  "info": { ... },                  // ← API 基本信息
  "servers": [ ... ],            // ← 服务器地址----可有多个
  "paths": { ... },              // ← 核心：所有接口定义
  "components": { ... },   // ← 可复用的组件----模型、安全方案等
  "security": [ ... ]           // ← 全局安全认证


在path部分中，一个路由对象/operation对象是这个样子的
"/users": {                                      //←路由名称,这个不包含在operation对象中
"get": {
  "operationId": "get_users",          // ← 唯一标识符----默认用函数名
  "summary": "获取用户列表",              // ← 短摘要
  "description": "分页返回所有用户",    // ← 详细描述
  "tags": ["用户管理"],                    // ← 分组标签
  "parameters": [ ... ],                    // ← 参数定义----查询参数、路径参数、请求头等
  "requestBody": { ... },                 // ← 请求体---POST/PUT 用
  "responses": { ... }                     // ← 响应定义----必须存在
}

requestbody参考上文
}


在operation对象中，requestBody长这个样子
"requestBody": {                          // ← 1. 请求体
    "content": {                              // ← 2. 内容
        "application/json": {             // ← 3. 数据格式
            "schema": {                     // ← 4. 数据模型结构
                "required": ["name", "price"],   // ← 必填字段
                "type": "object",                       // ← 数据类型：对象
                "properties": {                         // ← 对象的属性列表
                    "name": {"type": "string"},
                    "price": {"type": "number"},
                    "description": {"type": "string"}

设置响应状态码
JSONResponse：FastAPI会自动将大部分返回的响应值转换成JSONResponse格式，这是默认的返回值的响应格式
需要精细控制的时候，必须直接使用JSONResponse类包装
#这里主要了解状态码的手动设置，除此之外，这个方法还可以设置添加响应头，返回非字典类型等


使用方法
@app.put("路径")
async def 函数()
         return JSONResponse(status_code=状态码, content={内容})

#未在路由中声明直接使用jsonresponse方法的时候，OAS中是不包括这个状态码的----OAS:openapi.json
#如果想要在OAS中包括这些内容，需要在路由中声明新的状态码，以下：
@app.put("路径"，responses={403: {"description": "禁止访问"}})

响应格式Response
返回json格式的方法有三种：
1.设置响应模型，自动会翻译成json格式
@app.post("/items/", response_model=Item)
2.默认情况下，其它数据会先经过 jsonable_encoder 编码再自动转换成json格式
3.手动使用JSONResponse类转换成json格式

也可以不使用json格式自定义返回数据的格式，以下：
#返回一个xml数据
data=xml数据
return Response(content=data, media_type="application/xml")

#使用Reponse可以直接返回数据格式本身
Response(content=内容，media_type="数据格式")

HEML响应
#html响应有两种使用方法，使用响应类或者直接返回响应对象
1.使用响应类
@app.get("/items/", response_class=HTMLResponse)          #再路由中声明响应类，文本内容要写很长，优点是可以在交互文档中显示
 return """  html文本内容 """
2.直接返回响应对象
@app.get("/items/")
async def read_items():
       html_content = """html文本内容"""
       return HTMLResponse(content=html_content, status_code=200)    #直接返回响应对象，无法显示在交互文档中，优点是方便优雅

#当两者都使用时，既可以在文档中显示响应类型又可以优雅的返回响应对象
以下：
@app.get("/items/", response_class=HTMLResponse) 
async def read_items():
       html_content = """html文本内容"""
       return HTMLResponse(content=html_content, status_code=200)



7个可选响应
#通常响应类的参数有4个
#content：返回内容-str 或者 bytes格式；status_code：状态码-int格式
#headers：响应头-由字符串组成的 dict；media_type：媒体类型-str格式，如"text/html"等
#content是必选，其它三个是可选

1.Response
最上层的父类，所有的响应类都继承自这个父类。可以自定义返回响应的类型
Response(content=data, media_type="application/xml")       #返回xml格式

2.HTMLResponse
参考上文

3.JSONResponse
默认的响应格式，如果没有”response_class=“的显示声明和响应类的直接使用，默认将数据转换成json格式

4.PlaintTextResponse
接受文本或者字节返回纯文本
@app.get("/", response_class=PlainTextResponse)
async def main():
    return PlainTextResponse(content="Hello World")

5.StreamingResponse
#标准流式传输，是流式传输的底层实现类
#EventSourceResponse是一种经过包装的符合SSE的流式传输类
可以使用本章的使用方式
async def fake_video_streamer():
    for i in range(10):
        yield b"some fake video bytes"
        await anyio.sleep(0)

@app.get("/", response_class=StreamingResponse)
async def main():
    return StreamingResponse(fake_video_streamer())    #这里没有content而是直接返回的一个函数
 
也可以用标准的StreamingResponse实现方式
@app.get("/", response_class=StreamingResponse)
async def main():
    for line in message.splitlines():
        yield line.encode("utf-8")

6.FileResponse
用来发送文件，也是流式传输但这不重要
#path - 要流式传输的文件的文件路径；headers - 任何自定义响应头，传入字典类型。
#media_type - 媒体类型字符串，没有声明fastapi会根据文件名称自己推断；filename - 文件名
使用方式
return FileResponse("large-video-file.mp4")
或者
@app.get("/", response_class=FileResponse)
async def main():
    return "large-video-file.mp4"

7.RedirectResponse
重定向的意义是引导用户访问正确的url，提升用户体验，常常用在登录和url维护上
使用方式
return RedirectResponse("https://typer.tiangolo.com")
或者
@app.get("/fastapi", response_class=RedirectResponse)
async def redirect_fastapi():
    return "https://fastapi.tiangolo.com"                    #默认状态码是307，也可以手动设置状态码



自定义响应----继承自Response的响应类
创建自定义响应类，以使用常规响应类的方式使用它
创建类
class CustomORJSONResponse(Response):
    media_type = "application/json"                #参数类型

    def render(self, content: Any) -> bytes:     #主函数
        assert orjson is not None, "orjson must be installed"
        return orjson.dumps(content, option=orjson.OPT_INDENT_2)
#定义一个类，类里面包含参数类型和主函数
使用方式
@app.get("/", response_class=CustomORJSONResponse)



全局响应类
#创建fastapi命令对象时，声明响应类型HTMLResponse可以使所有路径操作默认使用声明的响应HTMLResponse
app = FastAPI(default_response_class=HTMLResponse)
